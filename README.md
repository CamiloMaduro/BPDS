# Proyecto CRUD

## Descripción

Este proyecto consiste en el desarrollo de una aplicación CRUD (Create, Read, Update y Delete) como parte de una actividad académica. Su objetivo es implementar las operaciones básicas para la gestión de información utilizando buenas prácticas de desarrollo.

## Funcionalidades

- Crear registros.
- Consultar registros.
- Actualizar información.
- Eliminar registros.
